# Changelog

## 0.3.0
- Skeleton Loader: `nc-skeleton` widget (text, circle, rect and list / card / form / table presets) and the `nc-skeleton` plugin that covers a grid, list or form while its store loads, for Classic and Modern.

## 0.2.0
- Avatar and Avatar Group (`nc-avatar`, `nc-avatargroup`) for Classic and Modern, with `NC.avatar.AvatarUtil` for initials and colors.

## 0.1.0
- Package foundation: `NC.Version`, shared SASS globals (`$nc-`), folder layout for shared, Classic and Modern code.
